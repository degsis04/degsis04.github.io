## Source files and processing

- HarvestStat official release [v1.2](https://github.com/HarvestStat/HarvestStat-Africa/releases), published on [Dryad](https://doi.org/10.5061/dryad.vq83bk42w). Downloaded at exact Git commit `5b62fb5`; checksums in provenance file.
- [OSU Transboundary Freshwater Spatial Database 2024](https://transboundarywaters.ceoas.oregonstate.edu/spatial-datasets); 818 BCU shapes; SHA-256 in provenance.
- [Python code](scripts/harveststat_audit.py), [GitHub Actions workflow](../../.github/workflows/harveststat-audit.yml) (workflow path relative to repo root).

Data processing: parse source CSV; positive values, QC, year; aggregate by country/crop/year; overlay TFDD and HarvestStat admin polygons after EPSG:6933 transformation; apply same-country matching; select highest-area BCU only if its area fraction is >= 0.8. For unmatched or split areas retain crosswalk but do not duplicate yield across BCU.

**Crucial limitations:** The 134300 records are **not** 134300 independent yield measurements; seasons and products recur within each district/year. The 63 BCU are **not** all viable research units; a single crop-year observation suffices. Historical admin boundaries may change, qc_flag is an outlier heuristic, and agricultural locations are unknown within each administrative area. Polygon area shares are not crop shares. Subsequent analysis must audit true year coverage and irrigation exposure before model fitting.

## Research decisions

1. Select a small set of common crop names and a minimum of 10–15 reliable observed years within each candidate BCU; report the actual length of contiguous intervals.
2. Check per-country and per-basin historic border comparability, split-year and sample-selection problems; validate sensitivity to 70/80/90/95% dominance threshold.
3. Build irrigation-based agricultural masks (MIRCA-OS, possibly maps at finer resolution) and hydrological connectivity; do not infer irrigation source from basin membership.
4. Measure upstream hydroclimatic forcing independent of actual downstream regulated discharge. Use GRDC/MRC in-situ station data where accessible for validation.
5. Institute coding: distinguish legal provision from actual implementation; only use explicitly dated official provisions.
6. Report uncertainty clustered at basin/institutional regime level, not just district level.

## Asian extension

- Lower Mekong: [MRC observed discharge portal](https://portal.mrcmekong.org/time-series/discharge), [MRC procedures](https://www.mrcmekong.org/procedures/), [Vietnam NSO crop statistics by province](https://www.nso.gov.vn/en/statistical-data/). Cross-country harmonization not yet confirmed.
- Do not pool datasets until variable definitions, crop calendars, administrative geography and institutional levels are demonstrably comparable.

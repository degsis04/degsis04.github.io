This file describes the content of "Contours des bassins versants et réseau hydrographique du fleuve Niger" dataset 
Please refer to  for data citation:
Rouché, Nathalie; Dieulin, Claudine; Mahé, Gil; Paturel, Jean-Emmanuel; Bricquet, Jean Pierre; Olivry, Jean-Claude; Adeaga, Olusegun, 2025,
 "Contours des bassins versants et réseau hydrographique du fleuve Niger",
  https://doi.org/10.23708/FWC87Z, DataSuds

----------------------	
The compressed folders SIEREM_FleuveNiger_Rivers.zip contains : 
the hydrographic network of the Niger basin in ArcGis shapefile format and represented linearly.
(la couche du réseau hydrographique du bassin versant du fleuve Niger est représenté linéairement au format ArcGis)
 
----------------------
The compressed folders SIEREM_FleuveNiger_Rivers_Basin.zip contains :
- the 67 catchment boundaries in shapefile format (one .shp file per basin).
(contours des sous-bassins par répertoire d'une station hydrometrique du bassin versant du fleuve Niger)
- the monthly discharge data - unit in l/s - available issued from SIEREM (.txt format with semicolun separator)
 - watershed boundaries are represented by polygons
(débits mensuels issus du système d'informations SIEREM (.txt format avec separateur point-virgule)
les contours des bassins versants sont représentés par des polygones)

----------------------
The SIEREM_Calcul_WHC_FAO.pdf contains the specification paper for the WHC calculation.

The SIEREM_Notice_For_Basin_File_Use.pdf :  notice for the contents of the datasets and description of the files Gridded data,
 monthly flow rates, GIS layers
 
 The SIEREM_Notice_utilisation_fichier_bassin.pdf : Notice explicative du contenu des jeux de données et description
 des fichiers maillés, débits, contours de bassins versants
	
----------------------
Description :
Jeux de données SIG et débits mensuels par bassins versants d'Afrique de l'Ouest et Centrale. 
Les fichiers fournis sont des fichiers d'entrée des modèles (couches vecteur SIG au format shapefile) des bassins versants
constitués à partir des données cartographiques des 356 bassins référencés sous la base SIEREM. 
 http://www.hydrosciences.fr/sierem/produits/produits/livret.pdf

Tous les fichiers de données sont au format ArcGIS (shapefiles) :
les contours des bassins versants sont représentés par des polygones (dossier « SIEREM_FleuveNiger_Bassin.zip »)
le réseau hydrographique du bassin versant est représenté linéairement (dossier « SIEREM_FleuveNiger_River.zip»)
Le fichier au format mxd contient les propriétés d'affichages des informations géographiques gérées dans la carte (symbologie...).
Le fichier de métadonnées au format xml créé avec le logiciel ArcCatalog répond à la norme ISO 19115 relative aux métadonnées géographiques.
 Il contient les références à citer pour chaque type de données disponibles, la signification de la table attributaire, 
 le rectangle d'emprise de la carte etc.
Pour chaque station une chronique de débits mensuels issus du système d'informations SIEREM complète le jeu de données (format texte) 
SIEREM_ListedesStationsHydroduFleuveNiger.tab
